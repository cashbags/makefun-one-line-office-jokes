One single-line joke about office life, written by a program to
`/output/entry.txt`:

> I raised an IT ticket about the printer, and the printer raised one about me.

The printer is the office's most resented machine, and the IT ticket is
the office's own ritual for dealing with it — so the joke lets the machine
use the bureaucracy against the person who filed the complaint. The laugh
lands in the last five words. See `DESIGN.md` for the full reasoning and
the twelve-candidate tournament that picked this line.

Run it with `python3 main.py`. Deterministic, no network, no trailing
newline: 77 bytes, every time.
